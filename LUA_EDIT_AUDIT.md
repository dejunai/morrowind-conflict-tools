# Lua edit audit: `Data Files\MWSE` (2026-11-17)

This audit is a report only. No files were changed. Paths are relative to `Data Files\MWSE\`.

## How this was worked out (and its limits)

- **Original archives:** the first pass found none. The user then pointed to `K:DownloadsVortexmorrowind`, and §7 diffs every flagged file against those archives. §1–§6 are the first-pass findings; §7 corrects them.
- The originals that could be found:
  - **MWSE core:** pristine files from github.com/MWSE/MWSE at the installed commit `1dce8de6…` (`mwse-version.txt`). A control file (`SideBarPage.lua`) matched byte for byte. The core diffs below are exact.
  - **`mwdialog_backup\luafix\<run>\`:** copies that our own `mwdialog_luafix.py` saved before each of its 7 runs (Nov 11–16). These are the state before luafix ran, not necessarily the release, because some files had already been edited by then.
- **Attribution:** Antigravity's own session folders in `~\.gemini\antigravity\brain\` hold its patch scripts. Session `fcad6ca3` ran Nov 4–11, and session `0d3c3706` ran on Nov 16, with Nov 17 edits attributed to it by timing. Lines marked **AG script** are files those scripts write to. Antigravity also edited some files through its built-in edit tool, which leaves no script. Those files are attributed by timestamp and by the bugs report.
- **`.bak` files:** only three exist under `MWSE`. Two `.lua.bak` files were shipped by the mod authors: they are identical in staging and have 2021/2025 timestamps. The third is a config backup. The many other `.bak` files the user saw are in `mwdialog_backup\` (backups from our own `mwdialog_check` tool) and in luafix's backup tree. **Antigravity did not leave `.bak` files next to the Lua it edited**, apart from a one-off graphicHerbalism backup in `update_gh_log.py`.
- **Nothing here was tested in game.** Verdicts come from reading the code.

Verdicts: **real bug fix**, **harmless** (low-risk tweak), **overreach** (rewrites behaviour, adds features, changes a library's API, or works around a conflict inside a third-party file), **unknown** (no original to compare against).
Docs: **BUGS #n** = `LUA_MOD_BUGS.md` section n. **Guide X** = category X of `# Morrowind MWSE Lua Debugging & Repair Guide.MD`.
