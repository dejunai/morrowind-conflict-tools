# mwconsole: design notes and credits

mwconsole is by dejunai (part of the mwsuite). It gives the console commands, Tab completion, details of the selected object and the effect inspector in one mod, off until switched on in its MCM. It needs UI Expansion's console for completion, the mode keys and the details panel; without it, registered commands still work through the vanilla console's Enter key.

## Credits

It borrows ideas from the mods below. No code from the third-party mods is used. The same list is on the Credits page of its MCM.
